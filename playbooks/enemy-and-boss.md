# Enemy and Boss AI

## Design target

State the combat fantasy in player terms: hunted, outmaneuvered, pressured, outsmarted, or tested. Then identify the decision that makes that feeling possible.

## Specify the loop

| Field | Define |
|---|---|
| Perception | what can be sensed, certainty, delay, and blind spots |
| Intent | goal, target priority, and why it changes |
| Commitment | telegraph, duration, interruptibility, and cancellation |
| Counterplay | route, timing, tool, information, or resource response |
| Recovery | cooldown, reposition, exposure, and learning signal |
| Scaling | which pressure variable changes without breaking the rule |

## Tactical space

Use tactical queries, cover, influence, path, and reservation systems to create choices the player can perceive. Never optimize a flank, charge, or attack slot that removes the player’s last meaningful route without an explicit encounter rule and test.

## Acceptance slice

In a single greybox encounter, ask a player to predict the next commitment, name two viable counters, and explain the result after failure. Inspect the replay whenever their explanation differs from the trace.
