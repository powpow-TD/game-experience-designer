# Experience Engine: Game Design Frameworks

A practical Chinese-language Codex skill for turning gameplay systems, AI behavior, UI, narrative, and iteration into testable player experiences.

## Use

Copy this directory into your Codex skills directory, then ask Codex to use `experience-engine-game-design` with a game-design or game-AI planning problem.

## Contents

- `SKILL.md`: core frameworks and topic index
- `chapters/`: on-demand chapter-oriented references
- `glossary.md`: terminology
- `patterns.md`: reusable design patterns
- `cheatsheet.md`: decision support

## Attribution and scope

Inspired by and synthesized from: Tynan Sylvester, *Designing Games: A Guide to Engineering Experiences* (Chinese edition: 体验引擎：游戏设计全景探秘). This repository contains no book scans, OCR, full text, figures, or long excerpts. It is an independent, practical organization of design ideas for learning and discussion; consult the original book for authoritative wording and complete context.
