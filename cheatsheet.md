# AI Game Experience Cheatsheet

| Player report | Start with |
|---|---|
| “The enemy is random.” | Legibility Before Optimization; observable states and commitments |
| “My companion got me killed.” | Player-Priority Reservation; Failure Contract; Companion AI Specification |
| “The NPC lied to me.” | LLM Authority Boundary; world consequence model |
| “Difficulty feels rigged.” | Adaptive Difficulty Contract; protected achievements |
| “AI feels impressive but not fun.” | Player-Facing Role; Agency Budget; minimum playtest |
| “We cannot explain why the agent did that.” | AI Ownership and Explainability; Evidence Triangulation |
