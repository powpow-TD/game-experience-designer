# Chapter 3: Skill

## Core idea

Challenge should create learning and expression for players with different levels of mastery.

## Practical method

Classify failure as perception, reaction, planning, or coordination; preserve recovery.

## Game-AI application

Tune perception, reaction, strategy, and team behavior separately before touching raw stats.

## Review prompts

- What player expectation is this system creating?
- What evidence can a player perceive before the consequence matters?
- What smallest test could prove this reasoning wrong?
